# Coding Standards - 実装チェックリスト

## 命名規則

- [ ] ファイル：キャメルケース（`bookService.ts`）
- [ ] コンポーネント：パスカルケース（`BookCard.tsx`）
- [ ] ディレクトリ：ケバブケース（`book-review/`）
- [ ] 定数：スネークケース大文字（`MAX_RETRY_COUNT`）
- [ ] クラス：パスカルケース（`UserService`）

## コメント・ドキュメント

- [ ] JSDoc を複雑な関数に記述
- [ ] パラメータ、戻り値、例外を文書化
- [ ] TODO/FIXME コメントにはプリフィックス付与
- [ ] コード説明的なコメントは控える（コード自体が明確なら不要）

## TypeScript

- [ ] any 型を避ける（必要に応じて unknown, never 使用）
- [ ] インターフェース/型定義を活用
- [ ] ジェネリクスで型安全に
- [ ] strict mode を有効化

## React コンポーネント

- [ ] 関数コンポーネント + TypeScript で実装
- [ ] Props を interface で定義
- [ ] 一貫性のあるコンポーネント構造
- [ ] 副作用は useEffect で管理
- [ ] カスタムHook でロジック抽出

## エラーハンドリング

- [ ] try-catch で例外を適切にキャッチ
- [ ] 統一したエラーレスポンス形式
- [ ] ログに詳細記録
- [ ] ユーザーに伝わりやすいメッセージを返す

## パフォーマンス

- [ ] 不要な再レンダリング防止（useMemo, useCallback）
- [ ] 大きなリストは仮想化を検討
- [ ] 画像・アセット最適化

## コード品質

- [ ] Linter（ESLint）エラーゼロ
- [ ] Formatter（Prettier）でフォーマット統一
- [ ] テストカバレッジ 80% 以上を目標
- [ ] コード レビュー通過
