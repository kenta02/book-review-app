# Security - 実装チェックリスト

## 認証・認可

- [ ] ログインが必要なルートに `authenticateToken` を付けた
- [ ] 管理者専用のルートに `requireAdmin` を付けた
- [ ] 本人のみの操作は、service 層で本人か管理者かを確認した
- [ ] 401 と 403 の両方のテストを追加した
- [ ] レスポンスにパスワード（ハッシュを含む）を含めていない

## データ保護

- [ ] 機密情報は環境変数で管理し、`.env` をコミットしていない
- [ ] トークンを localStorage に保存していない

## API セキュリティ

- [ ] 入力を `server/src/validators/` で検証した
- [ ] エラーレスポンスに実装の詳細を含めていない
- [ ] 生の SQL は `replacements` でバインドした
- [ ] `dangerouslySetInnerHTML` を使っていない

## ログ

- [ ] `logger` を使い、パスワードやトークンを記録していない

## 依存関係

- [ ] `pnpm audit` の結果を確認した
