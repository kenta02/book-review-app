# Security - 実装チェックリスト

## 認証・認可

- [ ] JWT またはセッション認証を導入
- [ ] パスワードは bcrypt（cost: 12）以上でハッシュ化
- [ ] トークン有効期限を設定（アクセス: 1h、リフレッシュ: 7d）
- [ ] ログイン時のみ機密情報を送信（パスワードは返さない）
- [ ] 権限チェックを実装（自身のデータのみ編集可など）

## データ保護

- [ ] 本番環境では HTTPS 必須
- [ ] パスワード・API キーは環境変数で管理
- [ ] `.env.local` は `.gitignore` に追加
- [ ] 機密データはメモリのみで保持（localStorage 保存禁止）

## API セキュリティ

- [ ] CORS を明示的に設定（必要なオリジンのみ許可）
- [ ] レート制限を実装（ブルートフォース対策）
- [ ] 入力バリデーション（`express-validator` または Zod）
- [ ] SQL インジェクション対策（ORM またはプレースホルダ使用）
- [ ] XSS 対策（React 自動エスケープを信頼、dangerouslySetInnerHTML 避ける）

## エラーハンドリング

- [ ] エラーメッセージに実装詳細を含めない
- [ ] ユーザーには一般的なメッセージを返す
- [ ] サーバーログには詳細を記録

## 依存関係管理

- [ ] `npm audit` で脆弱性スキャン
- [ ] セキュリティパッチは優先度高で対応
- [ ] 月次で依存パッケージをアップデート確認

## 監査ログ

- [ ] 敏感な操作（ログイン、削除）をログ記録
- [ ] ログに個人識別情報を含めない
- [ ] ログファイルを保護し定期的にローテーション
