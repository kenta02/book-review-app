# Testing - 実装チェックリスト

## ユニットテスト

- [ ] テストファイルを `__tests__/` または `.test.ts` で配置
- [ ] 関数・ロジックの正常系・異常系をカバー
- [ ] エッジケースをテスト
- [ ] Vitest で実行確認
- [ ] 処理量に対して十分なテストを記述

## Component テスト

- [ ] コンポーネント描画をテスト
- [ ] Props による動作確認
- [ ] ユーザーイベント（クリック、入力）をテスト
- [ ] 条件分岐（if 文）をカバー

## API テスト

- [ ] モックでバックエンド不要に
- [ ] 成功・エラーレスポンスをテスト
- [ ] ネットワークエラーをシミュレーション

## フォームテスト

- [ ] バリデーション エラーをテスト
- [ ] 送信処理をテスト
- [ ] リセット機能をテスト

## E2E テスト

- [ ] 主要フロー（ログイン → 検索 → 投稿）をカバー
- [ ] クロスブラウザ対応確認（Chrome, Firefox）
- [ ] レスポンシブデザイン確認
- [ ] エラー画面の確認

## テストカバレッジ

- [ ] 80% 以上を目標
- [ ] `npm run test:coverage` で確認可能
- [ ] `coverage/` に HTML レポート生成
- [ ] CI で自動チェック

## テスト環境

- [ ] `vitest.config.ts` で設定済み
- [ ] `setupTests.ts` でグローバルセットアップ
- [ ] テストデータ（Fixtures）を定義
