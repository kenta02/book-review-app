# コードレビュー：PRレビュー/チェックシート

## 🎯 目的

レビュー実行フローと評価基準を標準化して品質と効率を保つ。

---

### 3ステップ PRレビュー手順

```
【Approve】良い実装、マージ OK
【Request Changes】修正が必要、再確認待ち
【Comment】アドバイス・フィードバック（修正推奨）
```

**コメントの種類：**

| 種別                | 内容例                               | 対応             |
| ------------------- | ------------------------------------ | ---------------- |
| **Critical** 🔴     | セキュリティ脆弱性、データ破損の恐れ | 修正必須         |
| **Important** 🟡    | パフォーマンス低下、設計改善推奨     | 修正推奨         |
| **Nice-to-have** 🟢 | コード可読性、慣例に沿った方が良い   | 参考情報         |
| **Nitpick** ⚪︎      | スタイル、フォーマット               | 修正不要（参考） |

---

## 📝 チェックシートテンプレート

```markdown
## コードレビュー チェックシート

### 基本情報

- [ ] PR の目的・スコープが明確か
- [ ] 関連 Issue / Ticket が参照されているか
- [ ] ブランチ戦略に沿っているか

### コーディング規約

- [ ] 命名規則に従っているか（PascalCase, camelCase, UPPER_SNAKE_CASE）
- [ ] TypeScript 型チェック通過
- [ ] JSDoc コメント記載（公開関数）
- [ ] コード行数：関数は <= 50行 程度、複雑度 <= 10

### テスト

- [ ] ユニットテスト追加 & パス
- [ ] 既存テスト破損していない
- [ ] テストカバレッジ 80% 以上
- [ ] モック・スタブ適切か

### セキュリティ

- [ ] 認証・認可チェック実装
- [ ] Secret キー環境変数で管理
- [ ] SQL インジェクション対策（Sequelize のプレースホルダ/replacements 使用）
- [ ] XSS 対策（dangerouslySetInnerHTML 未使用 or サニタイズ）
- [ ] CSRF トークン検証・SameSite Cookie

### パフォーマンス

- [ ] N+1 クエリ問題がないか
- [ ] 不必要な re-render がないか
- [ ] キャッシング戦略は適切か
- [ ] バンドルサイズ最適か

### アーキテクチャ

- [ ] ディレクトリ構成に従っているか
- [ ] 責務分離が適切か（コンポーネント → hooks → API）
- [ ] 循環依存がないか
- [ ] エラーハンドリング十分か

### ドキュメント

- [ ] README/ドキュメント更新
- [ ] マイグレーションファイル記載（DB 変更時）
- [ ] コミットメッセージ形式に従っているか

### その他

- [ ] 不要なログ文・デバッグコード削除
- [ ] lint/format ツール実行済み
- [ ] タイプスクリプト 型のワイルドカード（any）未使用

---

### 評価

- **Approve** ✅ - マージして問題なし
- **Request Changes** 🔴 - 修正が必要、再確認待ち
- **Comment** 💬 - アドバイス・フィードバック

### 修正後の確認

- [ ] 指摘事項をすべて修正
- [ ] 再度 CI が通過
- [ ] コミット追加 / 強制プッシュ確認
```
