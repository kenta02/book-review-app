## 開発フロー

### 1. 新しいフィーチャー追加時

```
① アーキテクチャ確認
   └─ フォルダ構造・モジュール設計

② コーディング規約確認
   └─ 命名規則・型定義・エラーハンドリング

③ バックエンド連携確認
   └─ API エンドポイント設計

④ UI/コンポーネント実装
   └─ Tailwind CSS・a11y

⑤ セキュリティ確認
   └─ 認証・データ保護

⑥ テスト実装
   └─ ユニット・E2E テスト
```

### 2. コードレビュー時

- コーディング規約 照合
- セキュリティ 確認
- テストカバレッジ 確認
- a11y 確認

## 各スキルの references

各スキルフォルダ配下には以下が含まれています：

- **SKILL.md** – スキルの概要と実装ガイドライン
- **references/examples.md** – 実装例・コードスニペット
- **references/links.md** – 公式ドキュメント・参考資料
- **references/checklists.md** – 実装時のチェックリスト

## 使用方法

### 1. 特定のスキルを学ぶ場合

```
skills/[スキル名]/SKILL.md を読む
  ↓
references/examples.md でコード例を確認
  ↓
references/links.md で詳細ドキュメントを参照
  ↓
references/checklists.md でチェック
```

### 2. 問題解決時

スキルの相互関係マップから関連スキルを確認し、該当スキルの README と references を参照してください。

### 3. AI エージェント活用時

AGENTS.md の「参照スキルガイド」の表に従い、作業種別に応じた Skill を参照してください。
例: 「レビュー投稿 API を実装して（backend-integration を参照）」

## メンテナンス

### スキル更新時

1. **SKILL.md** を更新
2. **references/examples.md** でコード例を更新
3. **references/links.md** で参考資料を追加
4. **references/checklists.md** でチェック項目を追加

### バージョン管理

各 SKILL.md の `version` フィールドを更新してください（例: `1.0.0` → `1.1.0`）。
