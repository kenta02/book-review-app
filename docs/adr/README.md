# ADR（Architecture Decision Record）

設計上の重要な意思決定を、「なぜそう決めたか」まで含めて残すための記録です。
コードを見れば「何をしたか」は分かりますが、「なぜそうしたか」「他に何を検討したか」は残りません。
後から参加する人や、将来の自分が迷わないために、判断の背景を短く書き残します。

## 書くタイミング

- 後から変えるのにコストがかかる選択をしたとき（認証方式、保存先、ライブラリ採用など）
- 複数の選択肢で迷い、比較して決めたとき
- 方針や規約と異なる判断をしたとき

## ルール

- ファイル名: `NNNN-短い題名.md`（連番、英小文字とハイフン）
- 書式は [`0000-template.md`](./0000-template.md) を使う
- 一度決めた ADR は書き換えない。変更するときは新しい ADR を作り、古い ADR の状態を「置き換え済み」にして新しい ADR へリンクする

## 状態の種類

| 状態         | 意味                       |
| ------------ | -------------------------- |
| 提案中       | 検討中。まだ決まっていない |
| 採用         | 決定済みで、現在の方針     |
| 却下         | 検討したが採用しない       |
| 置き換え済み | 後の ADR で方針が変わった  |
